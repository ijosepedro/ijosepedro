## Projeto em destaque

### [Emissor e Controle de Carregamentos — Logística Operacional](https://github.com/ijosepedro/logistica-operacional)

Aplicação full-stack para acompanhar o fluxo **da ordem de carregamento à conferência do peso real**.

- Cadastro, busca, histórico e emissão de ordens para impressão.
- Registro de pesagens, comparação entre previsto e realizado e histórico de correções.
- Dashboard, filtros operacionais, relatórios e exportação CSV.
- API com autenticação no back-end, validação de entradas e integração com PostgreSQL.
- Interface responsiva, testes automatizados e documentação de instalação e arquitetura.

**Stack:** Node.js · Express · TypeScript · React · PostgreSQL · Vite · Tailwind CSS · Zod · Vitest
